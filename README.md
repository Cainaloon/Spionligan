# Spionligan

Agentuppdrag för syskon och familjer. Barnen löser uppdrag tillsammans: de letar, fotar och samarbetar, och varje uppdrag slutar utanför skärmen.

Spela: https://cainaloon.github.io/Spionligan/

- Allt sparas i webbläsaren på den egna enheten. Ingen data skickas någonstans.
- Framsteg kan flyttas mellan enheter med en spara-kod under Chefens inställningar.
- Lägg gärna till sidan på hemskärmen, så öppnas den som en app.
